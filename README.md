
# Practical 6: INHERITANCE

## Subject
Problem Solving Using Object Oriented Programming (C++)

## Problem Statement
Implement different types of inheritance.

## Aim
To understand and implement different types of inheritance in C++.

## Theory
Inheritance is an important feature of Object-Oriented Programming. It allows a class to derive properties and member functions from another class.

- **Base Class:** The class whose properties are inherited.
- **Derived Class:** The class that inherits properties from another class.

## Types of Inheritance
1. Single Inheritance
2. Multilevel Inheritance
3. Multiple Inheritance
4. Hierarchical Inheritance
5. Hybrid Inheritance

## Technology Used
- Programming Language: C++
- IDE: Dev-C++

## Program
The C++ program demonstrates single inheritance using a base class A and a derived class B.

## Expected Output
